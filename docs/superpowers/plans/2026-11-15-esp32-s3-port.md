# ESP32-S3 Firmware Port Implementation Plan

> **Note, 17 November 2026:** esptool shows the connected board is an N16R8-type module (16 MB quad flash, 8 MB embedded PSRAM, CH343 USB-UART bridge), not the N8R2 this document names. It was flashed with `esp32:esp32:esp32s3:FlashSize=16M,PartitionScheme=app3M_fat9M_16MB,PSRAM=disabled,CDCOnBoot=default`. This document is kept as written. See the [17 November verification record](../../../reference_files/LINUX_VERIFICATION_2026-11-17.md).

> **For agentic workers:** Use superpowers:executing-plans to implement this approved scope. Steps use checkbox syntax for tracking.

**Goal:** The firmware compiles for the ESP32-S3 N8R2 with the decided pins and drives the local alarm from `ALARM,<0|1|2>` commands.

**Architecture:** `bsec_board_config.h` holds the chip check and all board pins. `alarm_command.h` gains a bounded serial pump and a polarity helper. `sharp_dust_limits.h` holds the pure dust sample rule. The sketch wires them together. Only the loop task writes `Serial`.

**Tech Stack:** arduino-cli 1.5.1, ESP32 core 3.3.12, BSEC2 1.10.2610, BME68x 1.3.40408, g++ 11.4.0, Python 3.10.12 with the pinned environment.

**Spec:** docs/superpowers/specs/2026-11-15-esp32-s3-port-design.md
